## Project Basic Info
### Tech Stack
Native HTML5 + custom handwritten CSS styling, deployed via GitHub Pages automatically.
### Core Positioning
A lightweight fan memory station built for NMIXX 2nd Macau Fan Concert held on June 28, 2025.
Target users are overseas NSWER fans. It provides on-site concert photo browsing, personal concert experience records and online communication space for both audiences and fans who couldn’t attend the offline event.

## User Division & Current Implemented Functions
I divide users into two groups: ordinary fans & photo creators (station fansite managers)
### 1. Completed & Online Functions (For Ordinary Fans)
1. Classified browsing page for concert photos sorted by performance tracks
2. Single picture favorite & collection function
3. Independent comment area under each photo album
4. Full-site unified public chat room for all fans to communicate
5. Interest tag matching, recommending relevant concert materials based on user preferences

### 2. Unfinished Modules (Creator Upload & Management, Planned for Subsequent Iteration)
There is no material upload entry on the current site. All concert photos are manually imported by me in advance.
Creator supporting tools are not developed in V1 version, follow-up optimization list:
1. Independent material upload entrance for station creators
2. Batch upload & album grouping management
3. Original image anti-theft watermark function
4. Creator background data dashboard (view picture browsing & favorite volume)

## Iteration Planning & Version Roadmap
### V1 (Current Online Version, P0 Core Demands)
Focus on ordinary fans’ core demands: browse concert photos, collect materials, comment and chat with fellow fans.
Limited by independent development time, we prioritize completing content display and basic social closed-loop, and postpone the development of creator upload & management module.

### V2 (Short-term Optimization Plan)
1. Complete creator upload channel and full set of supporting material management tools
2. Add risk control mechanisms for message & chat room: keyword interception, report & mute functions
3. Optimize page responsive layout to adapt to mobile browsing

### V3 (Long-term Iteration Plan)
1. Split the unified public chat room into independent rooms categorized by artists & stage topics
2. Optimize photo wall hover animation, clean redundant CSS styles to improve page loading speed
3. Add complete concert timeline diary module

## Complete Product Workflow (Matches Product Intern Capabilities)
This project allows me to go through the full workflow of vertical C-end fan products, consistent with daily work of product interns:
1. User Demand Research & Sorting
Collect feedback from overseas fans via social platforms, translate and sort all demands into Excel demand ledger; classify demands by P0/P1/P2 priority to confirm the core development scope of V1.
2. Function Design & Demand Document Output
Divide two types of user groups, design finished basic browsing & social functions, and write complete iterative implementation schemes for unfinished creator tools and security control modules.
3. Page A/B Test & Data Optimization
Make two versions of picture display layout, compare page stay duration and material collection conversion rate, launch the better version online in full volume.
4. Defect Sorting & Iterative Repair
Record page layout dislocation, display abnormalities and other problems in Excel, complete multiple rounds of regression testing to fix all page bugs.
5. Long-term User Feedback Operation
Operate overseas fan accounts to guide fans to visit the site, continuously collect feedback on album & chat experience, and accumulate optimization directions for subsequent versions.

## Follow-up Technical Optimization Plan
1. Write adaptive CSS to realize full-screen adaptation on mobile phones
2. Optimize photo wall hover animation, compress picture resources to speed up loading
3. Develop security risk control logic for comment areas and chat rooms
4. Build background modules including creator upload, album management and anti-theft watermark

## Template Deployment Guide
1. Fork this repository
2. Clone the project locally
3. Overwrite root index.html with your own page code
4. Delete the CNAME file if you do not have an independent domain name
5. Commit & push all files to the remote repository
6. Enter Repository Settings → Actions → General, enable read & write workflow permissions
7. Enter Repository Settings → Pages, select the gh-pages branch for automatic deployment
After deployment, the website access format: https://username.github.io/gh-pages-html-template/

# NMIXX澳门2025粉丝见面会记录站点
线上预览地址：https://zhidao111-svg.github.io/gh-html-nmixx-concert-page/
本项目基于开源静态网页模板二次开发，属于非营利性质的粉丝纪念静态网站。
全部代码遵循MIT开源协议，仅用于前端学习与粉丝圈内交流分享，禁止一切商业用途，无任何盈利行为。

## 项目基础信息
### 技术栈
原生HTML5 + 手写CSS样式，通过GitHub Pages实现自动部署上线
### 产品定位
为2025年6月28日NMIXX澳门第二场粉丝见面会打造的轻量化粉丝素材站点。
核心面向海外NSWER粉丝，为到场观众、无法亲临现场的粉丝提供现场饭拍浏览、个人观演记录、同好线上交流空间。

## 用户分层 & 当前已上线功能
我将用户划分为两类：普通粉丝、产出饭拍的站姐创作者
### 一、现已开发上线功能（面向普通粉丝）
1. 演唱会饭拍素材分区浏览页面，按照舞台曲目分类展示图片
2. 单张图片收藏功能
3. 每套图集配套独立留言评论区
4. 全站统一公共聊天室，供全体粉丝在线交流
5. 兴趣标签匹配机制，根据用户偏好推送相关演出素材

### 二、暂未开发模块（创作者上传管理功能，列入后续迭代计划）
当前站点无素材上传入口，所有现场图片均由我提前手动录入页面。
第一版未开发创作者配套工具，后续优化清单：
1. 为站姐创作者搭建独立素材上传通道
2. 批量上传、图集分组管理功能
3. 原图防盗水印功能
4. 创作者后台数据看板（查看图片浏览量、收藏数据）

## 迭代规划与版本路线

1. Fork本仓库

3. 将自制页面代码覆盖根目录index.html

7. 进入仓库设置→Pages，选择gh-pages分支自动部署
